# موقع المستشفى الإسلامي

موقع ثابت (HTML جاهز) بلا قاعدة بيانات وبلا مكتبات خارجية، مع لوحة تحكم لتعديل المحتوى.
الموقع نفسه في جذر المستودع، فيعمل كما هو على أي استضافة: تبدأ من `index.html` وكل الروابط بين الصفحات نسبية.

> الموقع حاليًا في **وضع المراجعة**: يظهر شريط تنبيه أعلى الصفحات، وتحمل وسم `noindex`، ويمنع `robots.txt` الزحف. بدّل الحالة من لوحة التحكم بعد اعتماد المحتوى.

## محتويات المستودع

| المسار | ما هو |
| --- | --- |
| `index.html`, `about.html`, `departments.html`, `news.html`, `gallery.html`, `careers.html`, `contact.html` | صفحات الموقع السبع |
| `news/` | صفحة مستقلة لكل خبر منشور |
| `assets/` | التنسيق (`css`)، السكربت (`js`)، والصور (`img`) |
| `admin/index.html` | لوحة التحكم (ملف واحد مكتفٍ بذاته) |
| `sitemap.xml`, `robots.txt`, `.htaccess` | ملفات SEO وإعدادات الاستضافة |
| `content.json` | كل محتوى الموقع في ملف واحد |
| `src/` | المصدر: قوالب الصفحات `render.js`، التنسيق، السكربت، لوحة التحكم، والصور الأصلية المجهّزة |
| `build.js` | يعيد بناء كل ما سبق من `content.json` و`src/` |

ما عدا `src/` و`build.js` و`content.json` و`tools/` فهو ناتج البناء. لا تعدّله يدويًا لأن البناء التالي يستبدله.

## تعديل المحتوى

**من لوحة التحكم (بلا أدوات):**

1. افتح `admin/index.html` في المتصفح وعدّل. تظهر التعديلات في المعاينة فورًا وتُحفظ في المتصفح نفسه.
2. اضغط «تصدير الموقع (ZIP)».
3. فكّ الملف المضغوط فوق جذر المستودع (استبدال الملفات)، ثم ارفع التغييرات (commit).

**للمطوّر:** عدّل `content.json` أو ملفات `src/` ثم شغّل:

```
node build.js
```

لا يحتاج `npm install`. يعمل على Node 16 فما فوق.

## قبل الإطلاق

- بدّل «حالة الموقع» في اللوحة من «مراجعة» إلى «منشور».
- راجع قائمة «قبل النشر» في صفحة «نظرة عامة» مع إدارة المستشفى: أوقات الدوام، رقم المقسم، قائمة الأقسام، عدد الأسرّة، والأخبار التجريبية.
- تأكد من أن «نطاق الموقع» في الإعدادات هو النطاق الفعلي، فعليه تُبنى الروابط الأساسية (canonical) وخريطة الموقع.
- احمِ مجلد `admin/` بكلمة مرور من لوحة الاستضافة. اللوحة بلا تسجيل دخول خاص بها.
- استضف خط Tajawal محليًا (ملفات woff2) بدل Google Fonts لتقليل الاتصالات الخارجية.
- استبدل الصور الصغيرة المصدر (`lobby` و`waiting` و`building`) بنسخها عالية الدقة.

## ملاحظات تقنية

- لا تعتمد الصفحات على JavaScript لعرض المحتوى؛ السكربت (7 كيلوبايت) يضيف حالة الدوام الحيّة بتوقيت عمّان والبحث في الأقسام والقائمة الموسّعة.
- القائمة الموسّعة (mega menu) تُملأ تلقائيًا من المحتوى: الأقسام، فقرات «من نحن»، آخر ثلاثة أخبار، وبيانات التواصل.
- الأيقونات مجموعة SVG واحدة مرسومة للموقع، تُرسل مرة واحدة في كل صفحة. أيقونة كل قسم ووجهة تُختار من لوحة التحكم.
- الصور بصيغة WebP بمقاسين مع `srcset`، وصورة الواجهة محمّلة مسبقًا، وباقي الصور تُحمَّل عند الحاجة.
- لكل صفحة عنوان ووصف خاصان، رابط canonical، وسوم Open Graph، وبيانات منظمة (Hospital وBreadcrumbList وNewsArticle).
- `.htaccess` يفعّل الضغط والتخزين المؤقت على استضافات Apache.
- نموذج «اتصل بنا» يفتح تطبيق البريد لدى الزائر. لربطه بخادم بريد يلزم نقطة استقبال على الاستضافة.
- `tools/prepare_images.py` مساعد لتجهيز الصور الأصلية (قصّ وتصغير وتحويل إلى WebP) عند إضافة صور جديدة إلى `src/img`.
